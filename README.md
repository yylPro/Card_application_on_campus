# 校园通信服务平台

学生 H5、小程序和运营商后台共用同一服务端：支持学校二维码分流、校园网预约、选号预占、宽带报修、配送/实名激活、工单履约和学生评价。

## 本地运行

```powershell
npm install
npm run dev
```

学生端：`http://127.0.0.1:4173/q/XXU-2026`  
运营商后台：`http://127.0.0.1:4173/admin/login`

本地后台初始账号为 `operator`，密码为 `campus-admin-2026`。这是开发配置，部署前必须通过环境变量覆盖。

## 内测手机号

开发和测试环境内置以下手机号：

- `13800000001`
- `13800000002`
- `13800000003`

它们获取短信验证码后，页面会显示本地测试验证码。其他号码不会返回验证码。生产环境无论使用什么号码都不会返回验证码，必须配置真实 `SMS_WEBHOOK_URL`。

## 手动内测流程

启动服务后，先打开内测夹具接口确认环境已经就绪：

`http://127.0.0.1:4173/api/dev/test-fixtures`

再从内测学校二维码入口开始：

`http://127.0.0.1:4173/q/TEST-2026`

内测数据均为虚拟数据，只在非生产环境可用：

| 场景 | 姓名 | 学号 | 手机号 | 推荐服务 |
|---|---|---|---|---|
| 完整选号交付 | 内测新生一 | TEST20260001 | 13800000001 | 新生选号预约 |
| 取消并释放号码 | 内测新生二 | TEST20260002 | 13800000002 | 新生选号预约 |
| 宽带报修闭环 | 内测学生三 | TEST20260003 | 13800000003 | 宽带故障报修 |

### 1. 完整选号交付

1. 从 `TEST-2026` 二维码入口进入 H5，选择“新生选号预约”。
2. 填写“内测新生一”的信息，选择任一内测号码和交付方式，点击“获取验证码”。页面提示的 6 位本地验证码即为测试验证码。
3. 勾选必要信息处理同意，提交订单。此时该号码应从选号列表消失，表示已预占。
4. 登录后台，在该订单中依次操作：将资格核验改为“核验通过”；服务状态改为“联系中”；再改为“已派单”并填写负责人；改为“已预约”并填写预约时间；改为“处理中”。
5. 设置配送状态为“已送达待激活”，再设置实名激活为“已实名激活”；填写处理结果。可同时测试补贴，选择“已结算”并填写大于 0 的补贴金额。
6. 服务状态改为“已完成”。回到 H5，使用同一手机号获取“查询验证码”查看进度，再点击“确认完成”，获取“确认验证码”并提交 1 至 5 星评价。

### 2. 取消并释放号码

1. 用“内测新生二”再次提交一个选号订单，选择与第一条不同的号码。
2. 确认该号码不再出现在 H5 选号列表中。
3. 在后台将该订单从“待受理”改为“已取消”。
4. 刷新 H5 选号表单，该号码应重新出现，说明预占释放成功。

### 3. 宽带报修闭环

1. 用“内测学生三”选择“宽带故障报修”，填写宿舍地址、时间和故障说明，获取提交验证码并提交。
2. 在后台依次完成“联系中 → 已派单（负责人）→ 已预约（时间）→ 处理中 → 已完成（处理结果）”。
3. 回到 H5 查询记录并确认完成、提交评价。

### 4. 必测异常

- 未勾选必要信息处理同意时，提交必须失败；
- 未填写负责人不能派单；
- 未填写预约时间不能进入“已预约”；
- 未填写处理结果不能完成；
- 选号订单未实名激活不能完成；
- 号码已被预占时，第二次提交同一号码必须失败；
- 不在上述内测名单中的手机号不显示本地验证码。

## 自动化测试

```powershell
npm test
```

测试使用临时数据文件，不修改 `data/db.json`，并覆盖：

- 学校动态二维码、分流页、H5 和小程序入口契约；
- 运营后台创建学校和动态二维码 PNG 生成；
- 模拟短信网关、必要信息处理同意和普通预约；
- 模拟学校资格核验接口的通过和拒绝结果；
- 选号预占及取消释放；
- 派单、预约、处理、完成、审计历史和学生确认评价；
- 数据库状态字段和短信网关调用契约。

CRM、正式号码库存、实名制和装维系统目前没有真实接口。测试只验证它们接入前的平台状态字段，不表示已完成生产联通。

## 上线前必须配置

- 受控数据库替代本地 JSON 文件；
- 真实短信、号码库存、CRM、实名制和装维接口；
- 生产后台账户、强密码、多因素认证和角色权限；
- HTTPS、日志审计、备份、监控和告警；
- 微信小程序 AppID、公众号凭证和合法业务域名。
